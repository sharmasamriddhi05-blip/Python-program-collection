# Python Programs Collection

A collection of beginner Python programs, each with comments explaining how it works.

## Programs

| File | What it does |
|------|--------------|
| `factorial.py` | Finds the factorial of a number using a loop and using recursion |
| `fibonacci.py` | Prints the Fibonacci series using a loop and using recursion |
| `struct_to_dict.py` | Converts a structure (class / dataclass) into a dictionary in three ways |

## How to run

Make sure Python 3 is installed, then in a terminal inside this folder:

```
python factorial.py
python fibonacci.py
python struct_to_dict.py
```

(On some systems use `python3` instead of `python`.)
